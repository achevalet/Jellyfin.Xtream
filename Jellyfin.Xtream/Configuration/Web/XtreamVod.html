Requests each movie's plot, genres, release date, runtime and TMDB id from the server when its metadata is first fetched, and on a full refresh. A movie with a TMDB id then takes its title and details from TMDB. When disabled, the server gets no request per movie, and Jellyfin looks movies up on TMDB by their title.
For a movie the server gives no TMDB id, links it to the first TMDB result for its title and year, so it takes its title and details from TMDB. When disabled, Jellyfin matches such movies on TMDB itself and only fills the details they lack. Only used when movie details are fetched from the server.
